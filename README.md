# Weight Converter — Objective-C / UIKit

An early iOS coursework project from 2016, completed while learning Objective-C through Coursera. Converts kilograms to stones, pounds, or grams using a segmented control.

## Concepts explored

- Small conversion functions separated from the UI action.
- Reading numeric input and selecting conversion behavior.
- Connecting UIKit controls to actions and displaying results.

## Project context

Preserved as historical coursework with the original application code. This documentation was added later. It is a small learning exercise with basic input handling.

## Exploring the source

The conversion functions and UI action are in `Coursera-project2/ViewController.m`. Open `Coursera-project2.xcodeproj` in Xcode to inspect the project. Compatibility with current Xcode and iOS versions has not been verified.
